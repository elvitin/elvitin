<p align="center"> 
  <b> 
    <a href="https://github.com/elvitin/ezychat" target="_blank">EzyChat (In progress)</a>
  </b>
</p>

A multi-user chat written in [Java](https://en.wikipedia.org/wiki/Java_(programming_language)) that uses [JavaFx](https://en.wikipedia.org/wiki/JavaFX) as its GUI technology, strongly based on WhatsApp. This application explores a series of features and techniques. The server's essential requirement is the use of [multithreading](https://en.wikipedia.org/wiki/Multithreading_(computer_architecture)) using [Java Threads](https://en.wikipedia.org/wiki/Java_concurrency), to allow multiple parallel lines of execution, one for each connected client. Communication occurs exclusively over the transport layer's [TCP](https://en.wikipedia.org/wiki/Transmission_Control_Protocol) protocol, meaning the underlying application layer protocol is the application itself, using [protobuf](https://en.wikipedia.org/wiki/Protocol_Buffers) for data serialization and deserialization.
